# HassMind v1.2.2 — Clipboard, secret lifecycle, chat emphasis

## 1. Clipboard trên HTTP LAN

`navigator.clipboard.writeText()` thường bị chặn khi dashboard được mở bằng `http://IP:8090` vì đó không phải secure context. UI mới thử Clipboard API trước, sau đó fallback sang `document.execCommand("copy")`. Nếu cả hai đều bị browser chặn, input được select để người dùng chỉ cần nhấn Ctrl/Cmd+C. Cùng helper được dùng cho Recovery Key và API token.

## 2. Password và Recovery Key

- `secrets/admin_password.txt` / `/run/secrets/admin_password` chỉ dùng khi database chưa có admin.
- Sau khi đổi/reset password, chỉ Argon2id hash trong SQLite được cập nhật. Không giữ plaintext password hiện hành để tránh tăng rủi ro lộ credential.
- Recovery Key bootstrap đến từ Docker secret/env. Khi rotate từ UI, key mới được ghi atomically mode `0600` vào `/data/secrets/admin_recovery_key` và được ưu tiên khi reset password.
- Với stack mount `/opt/hassmind/data:/data`, lệnh host để đọc key hiện hành là `sudo cat /opt/hassmind/data/secrets/admin_recovery_key`.

## 3. Chat `**...**`

Assistant response được parse tối thiểu cho cặp `**...**`. Nội dung bên trong được render thành `<strong class="chat-strong">` và tô màu; dấu `**` không hiển thị. Parser tạo text node/element bằng DOM API, không inject `innerHTML`.
