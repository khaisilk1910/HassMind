# HassMind v1.2.5 — Zalo Plain Text & Fast Home Assistant State Queries

## 1. Zalo không còn hiển thị Markdown thô

Outbound Zalo messages đi qua `app/message_format.py` trước khi gửi. Formatter:

- bỏ heading marker `#` / `##` / `###`;
- bỏ `**bold**`, backtick inline/code fence nhưng giữ nguyên nội dung;
- chuyển bullet Markdown `*`, `-`, `+` thành `•` / `◦`;
- chuyển horizontal rule Markdown thành đường phân cách Unicode;
- chuyển `<FollowUp label="...">` thành `💡 Gợi ý: ...` và không gửi XML/UI markup sang Zalo;
- decode HTML entity như `&#x20;`;
- không xử lý `_` như Markdown emphasis để không làm hỏng `entity_id` Home Assistant;
- câu trả lời dài được chia theo ranh giới đoạn trước khi gửi, thay vì cắt cứng giữa nội dung.

Agent cũng nhận prompt riêng khi `source=zalo`: plain text, emoji vừa phải, Unicode bullet và không Markdown/HTML/XML.

## 2. Truy vấn trạng thái nhanh hơn

### Snapshot trạng thái sống trong RAM

`HomeAssistantClient` tải một snapshot `/api/states` khi WebSocket Home Assistant kết nối và sau đó cập nhật snapshot bằng `state_changed`. Khi WebSocket đang sống, các truy vấn current-state đọc RAM thay vì gọi lại REST cho từng câu hỏi.

Nếu WebSocket rớt, cache chỉ được dùng trong `HA_STATE_CACHE_TTL` (mặc định 1.5 giây), sau đó tự fallback về REST. Sau service call, snapshot bị invalidate để không trả trạng thái trước hành động.

### Tool mới

- `ha_search_states`: tìm entity theo `entity_id` / `friendly_name` / `device_class`, không phân biệt dấu tiếng Việt, có lọc domain/state và trả compact attributes trong một lần.
- `ha_get_states`: lấy nhiều `entity_id` trong một snapshot.

System prompt yêu cầu ưu tiên hai tool này cho câu hỏi trạng thái hiện tại và không dùng `ha_history` nếu người dùng không hỏi lịch sử.

### Parallel read tools

Khi model trả nhiều tool-call chỉ-đọc trong cùng một round, HassMind chạy chúng bằng `asyncio.gather`. Tool có side effect vẫn chạy tuần tự. Các tool điều khiển/ghi dữ liệu không được đưa vào nhóm parallel-read.

### Context nhỏ hơn

- `AGENT_HISTORY_MESSAGES=24`
- `ZALO_HISTORY_MESSAGES=12`
- `PARALLEL_READ_TOOLS=true`
- `HA_STATE_CACHE_TTL=1.5`

Các biến này có default trong code nên nâng cấp từ `.env` cũ không bắt buộc phải thêm ngay.
