# HassMind v1.2.4 — Custom Integrations & Collapsible Admin UI

## 1. Thêm Integration trực tiếp từ Web Admin

Tab **Integrations** có nút **Thêm Integration**. Operator có thể tạo Custom HTTP Integration gồm:

- tên, ID, icon và mô tả;
- bật/tắt runtime;
- Base URL và health path;
- authentication `none`, Bearer token hoặc API-key HTTP header;
- credential lưu riêng trong `/data/secrets/integration_custom_<id>_secret`.

Metadata/config persist trong bảng SQLite `custom_integrations`. Sau create/update/delete, `IntegrationHub` được reconfigure tại runtime nên danh sách và health status cập nhật ngay.

## 2. Security boundary

Custom HTTP Integration chỉ thực hiện health-check GET. Nó **không** tự sinh generic tool để model gọi endpoint tùy ý. Các action nghiệp vụ vẫn cần typed adapter/tool có schema và policy cụ thể.

Credential không được lưu trong SQLite và không được API trả ngược. API chỉ trả `secret_configured=true/false`.

## 3. Giao diện Integrations

- Adapter tích hợp sẵn và Custom Integration được tách thành hai nhóm rõ ràng.
- Mỗi Integration dùng card `<details>` và **mặc định đóng**.
- Click header card để mở/đóng cấu hình.
- Layout responsive 3 cột trên màn hình rộng, 2 cột trung bình, 1 cột trên màn hình nhỏ.
- Health Status và Effective Policy được tách khỏi phần cấu hình.
- Form thêm mới cũng thu gọn và có thể mở bằng nút **Thêm Integration** trên page header.

## 4. API mới

- `POST /api/integrations/custom`
- `PUT /api/integrations/custom/{integration_id}`
- `DELETE /api/integrations/custom/{integration_id}`

Các endpoint yêu cầu admin session + CSRF giống các thao tác cấu hình nhạy cảm khác.
