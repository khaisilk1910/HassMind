# HassMind v1.2.3 — Integration Admin & Rich Chat

## 1. Integrations quản lý từ Web Admin

- Thêm catalog cấu hình runtime cho:
  - Camera TTS EZVIZ
  - IRIS FaceDetect
  - Zalo Bot Server
  - Wyoming Vietnamese TTS
  - Home Assistant custom components/policy
- Cấu hình non-secret persist trong bảng `integration_settings` của SQLite.
- Credential persist riêng dưới `/data/secrets` mode `0600`.
- API chỉ trả `configured=true/false` cho secret, không trả giá trị secret.
- Web Admin override cấu hình stack/environment cũ; có thể reset từng integration về stack/default.
- `IntegrationHub.reconfigure()` rebuild adapter ngay trong runtime mà vẫn giữ cùng object reference cho `ToolRuntime`.
- Zalo webhook auto-registration task được restart/stop theo cấu hình runtime mới.
- Stack mặc định không còn bắt buộc các Docker secret riêng của Camera TTS/Zalo.

## 2. Chat render Markdown đẹp và an toàn

Frontend có renderer nội bộ, không cần CDN/package ngoài, hỗ trợ:

- `#` ... `######` heading
- unordered/ordered list và nested list
- `**bold**`, `*italic*`, `~~strike~~`
- inline code và fenced code block
- horizontal rule
- blockquote
- bảng Markdown cơ bản
- chuẩn hóa `&#x20;`, `&#32;`, `&nbsp;`
- emoji ngữ cảnh cho heading/bullet: camera, cửa, đèn, quạt, điều hòa, nhiệt độ, độ ẩm, năng lượng, lỗi...

Renderer tạo DOM element và `TextNode`; nội dung LLM không được đưa trực tiếp vào `innerHTML`, vì vậy HTML do model sinh ra không được thực thi.

## 3. Tương thích nâng cấp

Cấu hình integration cũ trong `.env`, Docker secret hoặc environment vẫn được hỗ trợ làm fallback. Sau khi lưu từ Web Admin, runtime override được ưu tiên. Khi reset integration trong UI, HassMind quay về nguồn stack/default hiện có.
