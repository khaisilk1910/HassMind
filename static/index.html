HassMind API token

Đang tải
Token này dành cho client/API bên ngoài qua header X-HassMind-Token. Dashboard hiện dùng phiên admin, không lưu API token trong localStorage.

Tài khoản admin

Đã xác thực
admin_password.txt chỉ là mật khẩu bootstrap lần đầu. Sau khi đổi mật khẩu, HassMind chỉ lưu Argon2id hash trong SQLite và cố ý không ghi mật khẩu mới dạng plaintext trở lại file secret.
Đang tải policy mật khẩu… Đổi mật khẩu sẽ thu hồi các phiên khác.

Recovery Key

Đang tải
Recovery Key chỉ dùng khi quên mật khẩu admin. Hãy lưu offline hoặc trong password manager. Xoay khóa sẽ vô hiệu Recovery Key cũ ngay lập tức. Key xoay từ UI được lưu tại /data/secrets/admin_recovery_key; nếu host mount /opt/hassmind/data:/data thì có thể đọc bằng sudo cat /opt/hassmind/data/secrets/admin_recovery_key.

Security posture

Hardened
Khuyến nghị: chỉ mở port 8090 trong LAN/VPN. Nếu dùng reverse proxy HTTPS, đặt ADMIN_COOKIE_SECURE=true. Không đưa secret vào biến môi trường khi có thể dùng Docker secrets.

Ghi đăng nhập thành công/thất bại, đổi mật khẩu, reset và thu hồi phiên. Không ghi mật khẩu, Recovery Key hay session token.

Giới thiệu HassMind

Hướng dẫn nhanh từng nhóm tính năng của container và ví dụ sử dụng thực tế.

Phạm viHassMind là AI agent độc lập kết nối Home Assistant qua REST/WebSocket, có policy, audit và approval.
Nguyên tắcĐọc rộng, hành động theo allowlist; thay đổi automation/script phải qua proposal/approval.
Bảo mậtWeb admin bắt buộc đăng nhập; session HttpOnly + CSRF; log/audit redact secret; container chạy non-root.

Tổng quan

Hiển thị health, phiên bản HA, model LLM, DB, task nền và logging để biết hệ thống có sẵn sàng hay không.

Ví dụ: DB writable = No → sửa quyền thư mục data cho UID 10001.

Chat / Agent

Nhận yêu cầu ngôn ngữ tự nhiên, gọi tool Home Assistant/MCP/RAG theo policy rồi trả lời có ngữ cảnh.

Ví dụ: “Kiểm tra các đèn đang bật và tắt đèn phòng khách nếu an toàn.”

Integrations

Cấu hình adapter có sẵn hoặc thêm Custom HTTP Integration ngay trên Web Admin. Cấu hình persist trong /data, credential lưu riêng trong /data/secrets.

Ví dụ: nhấn Thêm Integration, nhập URL + /health + token rồi lưu; Integration mới xuất hiện ngay trong danh sách và Health Status.

Logs

Structured logging có request/session/component/latency/traceback. Dữ liệu nhạy cảm được che trước khi xuất console, file và ring buffer.

Ví dụ: dán Request ID từ lỗi UI để tìm toàn bộ chuỗi sự kiện.

Tool audit

Lưu dấu vết tool call vào SQLite để kiểm tra agent đã gửi gì và nhận gì. Arguments/result được redact trước khi lưu.

Ví dụ: xem tool nào đã gọi service sai entity.

HA events

Lưu các event gần đây để hỗ trợ chẩn đoán realtime rule và context.

Ví dụ: kiểm tra state_changed của cửa trước trước khi điều tra Event rule.

Approvals

Thay đổi automation/script đi qua diff, snapshot, optimistic lock, apply/verify và rollback nếu cần.

Ví dụ: duyệt thay đổi automation sau khi xem diff chính xác.

Scheduler

Chạy prompt daily hoặc interval. Job mới luôn disabled để người quản trị kiểm tra trước.

Ví dụ: 21:00 mỗi ngày tạo báo cáo năng lượng và trạng thái nhà.

Event rules

Kích hoạt agent theo entity/to_state với cooldown; rule mới disabled và vẫn chịu toàn bộ policy/approval.

Ví dụ: cửa mở lúc đêm → yêu cầu agent kiểm tra ngữ cảnh và thông báo.

Knowledge / RAG

Lập chỉ mục tài liệu cục bộ bằng SQLite FTS để agent tìm nội dung riêng của ngôi nhà/hệ thống.

Ví dụ: lưu mapping entity, hướng dẫn thiết bị và quy ước đặt tên trong knowledge/.

Settings / Admin

Quản lý API token, username, password, recovery, session và security posture. API token không còn nằm trên top bar.

Ví dụ: rotate API token sau khi nghi ngờ token cũ bị lộ và thu hồi các phiên lạ.

Docker hardening

Container non-root, drop toàn bộ capability, no-new-privileges, read-only root filesystem, tmpfs /tmp và secret file permissions.

Ví dụ: dùng docker-compose.yml + secrets/*.txt thay vì truyền token thẳng bằng environment.
